# Secure Identity Platform

A backend-focused Identity and Authentication platform built for learning
production-oriented authentication architecture and security engineering.

## Planned Features

- Password Authentication
- Email Verification
- Session Management
- Device Management
- Passkey / WebAuthn
- Face Verification
- Rate Limiting
- Login Attempt Protection
- Account Locking
- Security Events
- Audit Logs
